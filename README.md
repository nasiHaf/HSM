Healthcare Management System

A Streamlit web application for managing patients, doctors, appointments and clinics, with a built-in messaging feature between patients and their doctors.

Features
Patients: view all patients, search by name, find a patient's doctor, and view a patient's diagnoses
Doctors: view all doctors, search by name, list a doctor's patients, and see a doctor's department
Appointments: view all appointments, or search by date, patient ID or doctor ID
Clinics: view all clinics, search by name, and list the departments of a clinic
Messages: patients and doctors can exchange text messages and images (stored in MongoDB)
